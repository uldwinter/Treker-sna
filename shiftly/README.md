# Shiftly 3

Премиальный трекер работы, смен и выплат.

## Возможности

- несколько работ и источников дохода;
- фриланс и разовые подработки;
- ручной и автоматический график смен;
- основные и дополнительные смены;
- больничные, отпуск, обучение, командировки и отмены;
- корректировки времени, премии, штрафы/удержания и комментарии;
- расчёт gross/net, НДФЛ, ночных и переработок;
- график выплат: аванс + зарплата, еженедельно, раз в две недели, раз в месяц;
- расчёт периода и ожидаемой суммы к каждой дате выплаты;
- графики дохода и нагрузки на главной;
- Neon Auth + Neon Postgres/Data API;
- local-first режим с облачной синхронизацией после входа.

## Production

https://shiftly-pi.vercel.app

## Backend

Neon Postgres + Managed Auth + Data API. Пользовательские данные защищены RLS.

Ветка `shiftly-v3` хранит versioned production build. Исходный frontend также сохранён локально в рабочем артефакте проекта.
